# Aerophysic PMU & Buck Converter Simulator

A high-fidelity web-based simulator designed for analyzing transient responses in Power Management Units (PMU) and Buck Converters.

## 🚀 Features
- **Real-time Transient Analysis:** Visualizes voltage and current spikes during switching.
- **Stress Ratio Monitoring:** Automated red-alert system for avalanche breakdown thresholds.
- **Engineering Precision:** Configurable parameters for $V_{BUS}$, $R_{LOAD}$, $L_{PARA}$, and $R_{DS(on)}$.
- **Responsive UI:** Optimized for engineering workflows.

## 🛠️ Technologies Used
- HTML5, CSS3, JavaScript (Vanilla)
- Canvas API for real-time plotting

## 📐 Usage
Simply open `index.html` in any modern web browser to start the simulation.
